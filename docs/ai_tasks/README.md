# AI 协作任务单索引（产品/需求侧产出，不含实现代码）

这里放给 AI 编程模型的实现需求单。每张单子写清：背景、改动模块、数据契约、纯逻辑抽离、单测要点、验收标准、不在范围。实现交给模型，本人负责验收（DevEco 完整构建 + entry/src/test 全量单测全绿 + 真机走查）。

## 模型分工（固定）
- **DeepSeek**：树/图算法、数据结构、结构化 JSON 输出、纯业务计算与工具函数（运行在端侧、可离线单测），不写 UI。
- **豆包代码模型**：复杂 ArkTS 自定义 UI 渲染、依赖现有接口的业务接线、服务↔页面数据同步、SDK 报错修复。
- 文档与代码中不出现其他模型名称。

## 使用方法
1. 一次只派一个子任务，复制对应 md 全文给指定模型（算法给 DeepSeek、接线/UI 给豆包）。
2. 交付后按单子「验收清单」逐条核对：构建通过、全量单测绿、真机走查该路径。
3. 小步合入、每步可回滚；新功能置于 feature flag 后；联网能力永远有本地兜底。
