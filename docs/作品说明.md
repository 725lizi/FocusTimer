# FocusTimer 鸿蒙多端专注计时本 —— 作品说明

## 一、项目概述

FocusTimer 是一款基于 HarmonyOS NEXT（API 24）原生开发的**多端协同专注学习工具**，面向学生与自习场景，提供专注计时、笔记流转、AI 学习周报、桌面元服务卡片与数据安全加密等完整能力。

- 开发语言：ArkTS（声明式 UI）
- 应用模型：Stage 模型
- 兼容设备：手机 / 平板 / 穿戴设备
- 开源协议：Apache License 2.0
- 仓库地址：https://github.com/725lizi/FocusTimer

## 二、项目背景与解决的问题

在分布式多设备使用场景下，常见痛点包括：

1. **计时中断丢失**：专注过程中 App 意外退出，计时进度无法恢复；
2. **多端数据割裂**：手机记的笔记、平板看的进度无法自动同步，需要手动反复流转；
3. **学习反馈缺失**：只有计时数据，没有对学习行为的分析与改进建议；
4. **隐私安全隐患**：学习笔记明文存储，流转无管控。

FocusTimer 针对以上痛点，给出了"异常接续 + 分布式流转 + AI 分析 + 加密白名单"的完整方案。

## 三、核心功能

| 模块 | 功能说明 |
| --- | --- |
| 专注计时 | 5/15/25/45/60 分钟五档 + 自定义时长，结束弹窗提醒；专注免打扰模式与护眼提示 |
| 异常接续 | 计时状态机抽离为纯逻辑层，App 异常退出后自动恢复并继续计时 |
| 笔记流转 | 多端笔记编辑、科目分类、一键流转到平板等设备，支持 AI 解析 |
| 数据统计 | 日 / 周 / 月可视化报表，科目学习时长分布一目了然 |
| AI 智能周报 | 基于真实学习记录自动生成个性化学习建议 |
| 桌面元服务卡片 | 桌面小组件实时显示计时状态与今日目标，无需打开 App |
| 久坐提醒 | 长时间久坐自动提醒，联动穿戴设备 |
| 数据安全 | 加密文件夹、设备白名单、流转二次确认 |

## 四、系统架构设计

采用分层架构，UI 与业务解耦：

- **UI 层**：ArkUI 声明式开发 + Stage 模型，页面模块化；
- **业务层**：核心 Manager 模块——
  - `ContinuationManager`：异常接续
  - `SubjectTagManager`：科目标签
  - `FocusModeManager`：专注免打扰
  - `SedentaryReminderManager`：久坐提醒
  - `SecurityManager`：数据加密
  - `DeviceWhitelistManager`：设备白名单
  - `OfflineCacheManager`：离线缓存
- **数据层**：relationalStore 关系型数据库 + Preferences 首选项 + distributedDataObject 分布式对象 + FormKit 服务卡片；
- **AI 层**：`AIAnalysisService` 学习数据分析与智能周报生成。

## 五、测试方案

基于 HarmonyOS 官方测试框架 **Hypium**，共编写 **52 个单元测试用例**，覆盖核心业务逻辑：

| 测试文件 | 覆盖模块 |
| --- | --- |
| AIAnalysisService.test.ets | AI 周报生成、学习数据分析 |
| Continuation.test.ets | 计时异常接续、状态恢复 |
| FocusModeAndSedentary.test.ets | 免打扰、久坐提醒逻辑 |
| List.test.ets | 列表与数据管理 |
| LocalUnit.test.ets | 本地基础工具单元 |
| OfflineCacheAndCard.test.ets | 离线缓存、桌面卡片数据 |
| SecurityAndWhitelist.test.ets | 加密、设备白名单 |
| SubjectTag.test.ets | 科目标签管理 |
| TimerEngine.test.ets | 计时引擎状态机 |

> 说明：HarmonyOS Local Test 官方暂不支持在 Linux（GitHub Actions 云端）执行，且 API 24 SDK 需登录华为开发者中心下载，故单元测试在本地 Windows + DevEco Studio 环境运行。

## 七、编译与运行说明

前置条件：

- DevEco Studio（HarmonyOS NEXT，API 24 SDK）
- 鸿蒙模拟器或真机（模拟器可直接运行，无需正式签名）

构建与测试：

```bash
# 构建 HAP（debug，无签名）
hvigorw assembleHap --mode module -p product=default -p buildMode=debug --no-daemon

# 运行单元测试（52 个用例）
hvigorw test -p module=entry --no-daemon
```
