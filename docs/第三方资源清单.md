## 二、说明

1. **运行期第三方依赖为空**：应用根 oh-package.json5 的 dependencies 为空，最终用户使用 App 时不依赖任何外部第三方闭源组件。
2. **测试框架不进入发布产物**：hypium、hamock 仅在 devDependencies 中用于本地单元测试，不随 HAP 分发。
3. **自研组件不属于外部第三方**：entry 引用的 mindmap-harmony 是本团队自研的本地 HAR（文件存在于 entry/libs），其源码以独立工程 MindMap-HarmonyOS 开源（MIT），并已上架 ohpm 中心仓 1.0.0。
4. **无网络服务型第三方依赖**：应用不内置第三方统计、广告、崩溃上报 SDK；AI 请求由用户自配 Key 直接发往模型官方接口，不经过第三方中转。
