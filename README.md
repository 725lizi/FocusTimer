# FocusTimer 鸿蒙多端专注计时器
## 项目简介
基于HarmonyOS NEXT ArkTS开发的客户端专注计时工具，支持自定义专注计时、周数据报表、分布式多端数据同步。
## 核心功能
1. 自定义倒计时，计时结束弹窗提醒
2. 周专注时长可视化统计报表
3. 分布式数据流转，多设备同步计时状态
## 技术栈
ArkTS / HarmonyOS NEXT / DevEco Studio 模拟器开发
## 项目踩坑文档
根目录存放完整踩坑记录：弹窗语法报错、Flex布局畸变、废弃分布式API、空对象空值兼容四类问题解决方案。
## 运行教程
DevEco Studio导入项目，启动手机模拟器即可直接运行。
